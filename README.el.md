## Σχετικά με την εφαρμογή

Η εφαρμογή δημιουργήθηκε για να βοηθήσει τους υποψηφίους για την άδεια χειριστή μηχανημάτων έργου να προετοιμαστούν για τη θεωρητική εξέταση πιστοποίησης. Μπορείς να εξασκείσαι κεφάλαιο προς κεφάλαιο, μαθαίνοντας τις σωστές απαντήσεις καθώς προχωράς, και όταν νιώσεις έτοιμος, να δοκιμάσεις τις γνώσεις σου σε μια πλήρη προσομοίωση της πραγματικής εξέτασης, με χρονόμετρο και τις ίδιες συνθήκες βαθμολόγησης.

## Χαρακτηριστικά

**Εξάσκηση ανά κεφάλαιο** — 15 κεφάλαια ύλης, άμεση ανατροφοδότηση σε κάθε ερώτηση, με εμφάνιση της σωστής απάντησης όποτε χρειάζεται.

**Τελική εξέταση** — προσομοίωση της πραγματικής εξέτασης: 80 ερωτήσεις με σταθερή (μη αναλογική) κατανομή ανά κεφάλαιο από τράπεζα 448 ερωτήσεων, χρονόμετρο 90 λεπτών, και όριο επιτυχίας 75% (60/80). Ερωτήσεις μονής και πολλαπλής σωστής απάντησης.

**Επισκόπηση & πλοήγηση** — σημείωση ερωτήσεων «για επανεξέταση» κατά τη διάρκεια της εξέτασης, καθώς και πλήρης επισκόπηση όλων των ερωτήσεων (χρωματικά κωδικοποιημένο πλέγμα: απαντημένες / αναπάντητες / για επανεξέταση / μη ιδωμένες) για γρήγορη πλοήγηση.

**Ανθεκτικότητα** — η εξέταση δεν χάνεται ποτέ αν η εφαρμογή πάει στο παρασκήνιο, κλειδώσει η οθόνη, ή τερματιστεί η διεργασία από το λειτουργικό· η πρόοδος και το χρονόμετρο συνεχίζουν σωστά όταν επιστρέψεις.

**Ιστορικό** — καταγραφή των προηγούμενων προσπαθειών (ημερομηνία, σκορ, επιτυχία/αποτυχία), αποθηκευμένη τοπικά στη συσκευή.

## Τεχνολογίες

- Kotlin
- Jetpack Compose + Material 3
- Navigation-Compose
- kotlinx.serialization (ανάγνωση της τράπεζας ερωτήσεων από ενσωματωμένο JSON)
- Room (τοπικό ιστορικό αποτελεσμάτων)
- ViewModel + StateFlow (χωρίς εξωτερικό DI framework)
- minSdk 24 (Android 7.0)

## Δομή του project

```
app/src/main/
 ├── assets/                    questions.json, exam_config.json — η τράπεζα ερωτήσεων
 ├── java/.../
 │    ├── data/                 μοντέλα, repositories (ερωτήσεις, config, ιστορικό, κατάσταση εξέτασης)
 │    │    └── local/           Room: entities, DAO, Database
 │    ├── ui/
 │    │    ├── home/            Αρχική οθόνη + loading/splash
 │    │    ├── chapterlist/     λίστα κεφαλαίων
 │    │    ├── practice/        εξάσκηση ανά κεφάλαιο
 │    │    ├── exam/            τελική εξέταση
 │    │    ├── results/         αποτελέσματα εξέτασης
 │    │    ├── history/         ιστορικό προσπαθειών
 │    │    ├── about/           σχετικά με την εφαρμογή
 │    │    └── common/          κοινά components (OptionRow, κ.λπ.)
 │    └── navigation/           NavGraph
 └── res/                       εικονίδιο, γραφικά, strings.xml
```

## Build & εκτέλεση

```
git clone https://github.com/XaplanterisNikos/XeiristisExamQuiz.git
```

Άνοιξε τον φάκελο στο Android Studio, άφησε το Gradle να συγχρονιστεί, και πάτα Run σε emulator ή σε πραγματική συσκευή (Android 7.0+). Δεν χρειάζεται API key ούτε σύνδεση στο διαδίκτυο — η τράπεζα ερωτήσεων είναι ενσωματωμένη τοπικά στην εφαρμογή.
